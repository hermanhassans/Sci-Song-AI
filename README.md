# Sci-Song AI: Galaxy Mission

A Year 6 Science (Unit 11: Galaxy, DSKP 11.1.1 – 11.1.4) learning website with songs, games, a 3D VR galaxy and the storybook *Zak’s Missing Star / Bintang Zak Yang Hilang*.

Institut Pendidikan Guru Kampus Kent, Tuaran, Sabah · © MyIPO LY2026S10341

## Files
- `index.html` – the whole website (songs are built in)
- `storybook/Zaks-Missing-Star.pdf` – the storybook shown on the Storybook page

## Publish with GitHub Pages
1. Upload both files (keep the `storybook` folder).
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
3. The site appears at `https://<username>.github.io/<repository>/` after a minute or two.
